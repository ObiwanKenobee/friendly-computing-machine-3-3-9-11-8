````
# 🚀 Getting Started

## Requirements

Install:

- Node.js >= 20
- npm/yarn
- Docker
- PostgreSQL

---

## Clone Repository

```bash
git clone https://github.com/quantumvest/quantumvest-aladdin-ai.git

cd quantumvest-aladdin-ai
````

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment

Create:

```
.env
```

Example:

```env
DATABASE_URL=
AI_API_KEY=
BLOCKCHAIN_RPC_URL=
WALLET_PROVIDER=
NEXT_PUBLIC_APP_URL=
```

---

## Run Development Server

```bash
npm run dev
```

Application:

```
http://localhost:3000
```

---

# 🧪 Testing

Run all tests:

```bash
npm test
```

Coverage:

```bash
npm run test:coverage
```

# 🐳 Docker Deployment

Build:

```bash
docker build -t quantumvest-ai .
```

Run:

```bash
docker run -p 3000:3000 quantumvest-ai
```
